# DCOMP320 – Stack-Based Expression Evaluator (Version 2: Postfix Approach)

Reads mathematical expressions from `input.txt`, evaluates each using stacks, and writes the results to `output.txt`.

## Requirements
Python 3.8+ (standard library only).

## How to run
```
python expression_evaluator.py                      # input.txt -> output.txt
python expression_evaluator.py my_in.txt my_out.txt # custom file names
```

## Files
| File | Purpose |
|---|---|
| `expression_evaluator.py` | Source code |
| `input.txt` | Sample input used for testing |
| `output.txt` | Output generated by the program |

## Input format
One expression per line; expressions are separated by a line of three or more dashes (`-----`). Supported: `+ - * /`, parentheses, decimals, unary minus, spaces.

```
3 + 5 * 2
-----
(8 / 4) + 7 * 2
-----
10 - (2 + 3) * 4
```

## Output format
Same layout as the input, each expression replaced by its result, same separators kept.

```
13
-----
16
-----
-10
```

## How it works
1. **Infix → postfix** with a stack (Shunting-Yard): `3 + 5 * 2` becomes `3 5 2 * +`.
2. **Postfix evaluation** with a second stack: numbers are pushed; an operator pops two operands, computes, and pushes the result.

The `Stack` class is built from linked nodes (`push`, `pop`, `peek`, `is_empty`, `size`).

## Assumptions and limitations
- Division is true division (`7 / 2 = 3.5`). Whole-number results print without `.0`; others up to 6 decimals.
- Invalid expressions produce `Error: <reason>` on that line (division by zero, mismatched parentheses, invalid expression/character); the program continues.
- Blank lines are ignored. A missing input file gives an error message.
- Exponents, functions and variables are not supported.
- The assignment sheet's sample output shows `17` for `(8 / 4) + 7 * 2`; the correct value is `2 + 14 = 16`, which this program outputs.
